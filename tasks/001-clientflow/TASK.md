# 001 — ClientFlow
Запрос: реализовать приложение по приложенному заданию, соблюдать AGENTS.md и загрузить в mendjicode/ClientFlow.

Исходное состояние: только AGENTS.md и README.md, предыдущих задач нет.

План:
1. Модульное приложение HTML/SCSS/Bootstrap/JavaScript, сборка Gulp.
2. Dashboard, заказы и карточка заказа, клиенты, финансы, время, шаблоны, настройки.
3. Локальное сохранение, отдельный демонстрационный набор, Supabase Auth, PostgreSQL и RLS.
4. Проверки логики, браузерных сценариев и сборки, документация, отправка в GitHub.

Состояние: начата реализация. Внешний Supabase не настроен, ключи не предоставлены.

## Итог реализации

Созданы:
- `src/index.html`, `src/scss/app.scss`: адаптивная оболочка, тёмная/светлая тема, формы, таблицы, карточки, диалоги.

- `src/js/store.js`: локальное сохранение и Supabase Auth/Database/Storage, изоляция деморежима, таймер.
- `supabase/schema.sql`: 12 таблиц, RLS, составные внешние ключи, приватный Storage.
- `.env.example`, `.gitignore`, `package.json`, `package-lock.json`, `gulpfile.js`, `playwright.config.js`, `.github/workflows/checks.yml`.
- `tests/domain.test.js`, `tests/rls.test.js`, `tests/browser/app.spec.js`.
- `tasks/001-clientflow/REQUEST.md`: исходное задание; `screenshots/`: снимки широкого и мобильного экрана.
Изменён README.md: сохранён заголовок, добавлены запуск, подключение Supabase, возможности и ограничения. AGENTS.md не изменён; исходные файлы не удалялись.

## Что требует настройки владельцем
Создать Supabase, выполнить схему, заполнить .env публичными параметрами, настроить Auth URL/SMTP и проверить настоящие регистрацию/письма/Storage. Внешний сервис без предоставленных настроек не подключался. Описанные в README ограничения: простой текстовый редактор ТЗ, PDF через печать, нет фоновых уведомлений/импорта JSON/командных пространств/автосинхронизации между вкладками; удаление метаданных не очищает объекты Storage.
